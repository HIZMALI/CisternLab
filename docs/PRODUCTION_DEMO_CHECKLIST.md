# Production demo checklist

Use the verified public links and current verification status in [release links](DEVPOST_RELEASE_LINKS.md). All outputs are estimated. ERA5 is modeled reanalysis; synthetic demos are authored and archived data is a dated preserved download.

1. Open the application. In the overview, identify the problem: rainfall timing and tank capacity determine how much non-potable demand can be served. Neither annual rain nor tank size alone establishes savings.
2. Keep the initial **DEMO DATA — SYNTHETIC** example. Observe 7,250 L delivered, 5,650 L overflow and 1,500 L remaining over 30 days. Change roof, demand or capacity; charts and the complete daily table update locally.
3. Open **Tank Sizing**. Read the empty-start assumption and adjustable 90% relative-yield heuristic. Inspect candidate and marginal tables; export sizing CSV. The recommendation does not overwrite the dashboard tank.
4. Open **Impact & Evidence**, wait for **Archive verified**, then choose **Explore Archived Edirne Example**. This needs the local archived asset, not a weather API request. Use roof 120 m², efficiency 80%, demand 250 L/day, current tank 2,000 L, alternative 3,000 L and target 90%.
5. Inspect 2023, 2024 and 2025 as independent empty-start years. The current tank delivers 114,591.6 L in total; the selected 3,000 L tank delivers 120,687.2 L. Their increment is 6,095.6 L over these three years. These are conditional model estimates, not measured real-site savings. Ending storage is excluded.
6. Expand **Inspect impact source & original provenance**. Check all 1,096 dated values, original source URLs, requested/grid coordinates, retrieval times, ERA5 classification, SHA-256, Open-Meteo/Copernicus/GeoNames credit and CC BY 4.0. Download the original snapshot to reproduce without fresh weather access.
7. Start the evidence walkthrough. Use Next through all four stages; check Back, then Exit. Keyboard focus follows the stage heading and returns to the launch button. The selected analysis stays intact.
8. Use **Copy Key Findings**. Confirm source, period, units, inputs, empty starts, decision and the **ONLY IF** substitution condition. Use the text fallback if clipboard permission is denied.
9. Use **Print / Save Evidence Brief**, choose A4 and Save as PDF. The verified Chromium capture has four pages; actual browser settings can change pagination. Check results, methodology, all source records, attribution and caveats. Navigation is excluded.
10. To demonstrate a fresh source, return to **Simulator → Historical Reanalysis**. Search Edirne and explicitly select Edirne, Türkiye, ID 747712; select a complete year (2025 default) and **Load rainfall data**. Inspect complete-day validation and provenance. The public non-commercial API may be unavailable; display the actual error and use the archive if needed.
11. With validated historical data active, inspect **Tank Sizing**, then **Historical Variability Lab → Load three-year comparison**. Wait for all three years to validate. Export reproducibility JSON and comparison CSV. In Impact & Evidence, select **Use loaded three-year comparison**. It remains distinct from the archived example.
12. Export daily CSV from the dashboard. Confirm date/rainfall/provenance and unrounded calculations. Physical-input edits use cached data and make no weather requests.
13. Test a narrow viewport/mobile menu and keyboard links, controls, table scrolling and visible focus. Automated axe results do not establish full WCAG certification.

Same-page offline archive use works after required assets are prepared. First-ever offline access, offline reload and persistent caching are not provided. Do not promise site-specific engineering, drinking-water suitability, financial returns, carbon savings, forecasts or guaranteed service.
